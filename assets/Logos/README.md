O logotipo da TOU: o "tou" com o símbolo de dois arcos no gradiente ciano. Use os arquivos como estão; não redesenhe, não recolora, não aplique sombra nem contorno.

- `tou-logo-cor.webp` (gradiente `brand-blue → brand-teal`): o logo de uso geral, em fundos claros (`bg-surface`, `bg-page`, papéis) **e escuros** (`navy`, `dark`), como o site atual já usa no hero.
- `tou-logo-branco.webp`: versão branca com cerca de 10% de opacidade (marca-d'água). Não serve como logo de cabeçalho ou rodapé; use só como textura discreta sobre `ink-950`/`gray-950`. Falta um arquivo branco sólido para fundos escuros.
